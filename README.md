# PURZONE

PURZONE is an independent local community information platform for Pur, Bhilwara, Rajasthan.

## Current version
- Responsive landing page
- Local service categories: rentals, jobs, businesses, buy/sell, updates, lost & found
- Demo listing and issue forms using browser localStorage only
- Links to official Rajasthan Sampark and Jan Soochna portals
- Clear disclaimer that PURZONE is not an official government or elected-representative website

## Important
The current forms are a front-end prototype. They do not submit data to a shared database, notify an admin, or publish listings to other visitors. Add a secure backend, moderation workflow, spam protection and privacy controls before using it as a public listing service.

## Deployment
Static HTML project. Connect this repository to Vercel with the project root set to `/`. No build command is required; output can be the project root.
